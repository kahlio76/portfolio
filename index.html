persona-discord
ios · native

        
A native iOS Discord client that looks like the Persona 5 phone. Servers and DMs both work, streamed live over the gateway and rendered in P5's jagged chat bubbles.

        

          
demo the chat UI, with a fake gateway feeding it0 events

          

            

            

              
              
              
            

            
Press replay to stream a conversation in, or send something and the group chat answers.

          

        

        
    
          
  • Started from an Android P5 messenger demo that was only a mockup, with no backend and nothing to talk to. I threw out the Android code and rebuilt it from scratch in Swift as a native iOS app.
    • 
          
  • Wired it to the Discord API: REST for history and sending across servers and DMs, and a persistent WebSocket gateway connection so messages land the moment they're sent instead of on a poll.
    • 
          
  • Reworked the UI on top of the original look: redrew the bubble shapes, added the connector stripes that tie each bubble to its speaker, and swapped the typeface.
    • 
          
  • I use it on my own phone. Installed straight from Xcode rather than the App Store.
    • 
        

        
Swift · iOS · Discord REST API · WebSocket gateway · custom UI
